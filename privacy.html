Dalfocal 개인정보 처리방침

Dalfocal(달포컬)은 내 PC에서 쓰는 작업 보드 앱입니다. 계정도 서버도 없이 쓸 수 있고, 데이터는 기기 안에 저장됩니다. 밖으로 나가는 것은 아래에 적은, 사용자가 직접 켠 기능뿐입니다.

시행일: 2026-11-01 · 최종 수정: 2026-11-01

달포컬 1을 쓰는 분은 달포컬 1 개인정보 처리방침을 보세요.

1. 처리 주체와 연락처

  • 처리 주체: 달스튜디오(Dalstudio). Microsoft Store 게시자 이름은 Dalfocal, Google Play 개발자 이름은 Dalproject이며 모두 같은 운영자입니다.
  • 앱 이름: Dalfocal
  • 문의: support@dalfocal.com

2. 기본 원칙

  • 프로젝트·보드·컬럼·카드·노트·할 일·메모·댓글·라벨·첨부파일·설정은 사용자 기기에 저장됩니다.
  • 회원가입이나 로그인이 없습니다. Dalfocal 계정이라는 것이 없습니다.
  • 광고 SDK, 사용 행태 분석·추적 SDK가 없습니다. 사용 통계를 보내지 않습니다.
  • 크래시 보고를 보내지 않습니다.
  • 데이터가 기기 밖으로 나가는 기능은 모두 기본이 꺼져 있고, 사용자가 켤 때만 동작합니다.

3. 처리하는 데이터

기능데이터어디서 어떻게
앱 기본 기능프로젝트·보드·카드·노트·메모·댓글·라벨·체크리스트·설정, 사용자가 고른 첨부파일기기 안 데이터 폴더(설정 → 데이터 위치에서 바꿀 수 있음)에 저장. 전송 없음.
기기끼리 동기화(선택)동기화하는 프로젝트·카드·노트·설정과 첨부파일, 기기 이름·무작위 기기 식별자, 변경 순서사용자의 기기 중 하나가 «서버»가 되고 다른 기기가 초대(QR·연결 문자열)로 연결됩니다. 기기와 기기 사이는 TLS로 직접 연결하고, 상대 인증서 지문을 초대에 고정해 확인합니다. 달스튜디오나 제3자 서버를 거치지 않습니다. 데이터는 보내는 기기에서 AES-256-GCM으로 암호화한 뒤에만 나갑니다. «이 기기를 서버로» 켠 기기는 동기화 암호 키를 갖고 있습니다. 사용자가 직접 실행한 중계 서버에는 암호 키가 없고, 암호화된 데이터만 보관합니다. 보관한 데이터는 모든 기기가 받으면 삭제합니다. 연결에 쓰는 암호 키는 기기 보안 저장소에 둡니다.
폰에서 AI 채팅(선택)폰에서 보낸 대화 글과 그 답폰이 PC의 AI를 빌려 씁니다. 명령과 답은 동기화와 같은 연결로, 같은 동기화 암호 키로 암호화해서 주고받습니다. PC에서 켠 기기만 쓸 수 있고, 쓸 방식도 PC에서 고릅니다. PC에서 내 API 키를 쓰면 글이 PC를 거쳐 그 AI 회사로 나갑니다. API 키는 폰으로 보내지 않습니다.
AI 앱 연결, MCP(선택)연결한 AI 앱이 요청한 카드·노트 내용사용자가 설정 → AI → «외부 AI 앱 연결(MCP)»을 켜면 Claude Desktop·Claude Code·Cursor 같은 AI 앱이 이 기기 안에서 Dalfocal을 띄워 카드·노트를 읽고 저장합니다. 프로그램을 띄울 수 없는 앱은 이 PC의 로컬 주소(loopback)와 발급한 토큰으로만 연결합니다. 그 AI 앱이 내용을 어디로 보내는지는 그 앱의 정책을 따릅니다.
앱 안 AI 대화, 내 PC 모델(선택)대화 글, 대화 중 AI가 읽은 카드·노트, AI가 만든 카드·블록이 PC에 설치된 로컬 모델용 프로그램(Ollama, goose 등)과 대화합니다. 프로그램은 사용자가 고를 때만 Dalfocal이 연결합니다. 로컬 모델을 쓰면 대화는 이 PC 안에서 처리됩니다. 사용자가 그 프로그램을 클라우드 모델로 설정하면 글이 그 모델의 서비스로 나가고, 처리는 그 서비스의 정책을 따릅니다. Dalfocal은 대화 내용을 저장하지 않고, 창을 닫으면 대화가 사라집니다. goose를 쓰면 goose가 이 PC에 대화를 저장할 수 있고, Dalfocal에서 이 저장을 끌 수 없습니다. AI에게 시켜 만든 카드·노트와 «대화 중 블록 자동으로 남기기»(기본 꺼짐)로 남긴 블록은 Dalfocal 데이터로 저장되고 동기화 대상입니다. 저장 여부를 확인할 때 미리보기가 잠깐 기기 안 앱 데이터에 들어갑니다. 음성 입력은 기기의 음성 인식이 글로 바꾸고 Dalfocal은 소리를 저장하지 않습니다.
앱 안 AI 대화, 내 API 키(선택)대화 글, 대화 중 AI가 읽은 카드·노트, AI가 만든 카드·블록내 API 키를 쓰면 대화 글과 대화 중 AI가 읽은 카드·노트가 사용자가 고른 AI 회사로 나갑니다. 앱에서 그 회사로 바로 연결하고 달스튜디오 서버는 지나지 않습니다. 처리와 보관은 그 회사의 약관을 따르고, 요금도 그 회사에 사용자가 직접 냅니다. Dalfocal은 대화 내용을 저장하지 않고, 창을 닫으면 대화가 사라집니다. AI에게 시켜 만든 카드·노트와 «대화 중 블록 자동으로 남기기»(기본 꺼짐)로 남긴 블록, 저장 확인 때의 미리보기는 위 내 PC 모델과 같습니다. API 키는 이 기기의 암호화 저장소에 보관합니다. 사용자가 주소를 직접 적을 때는 https만 받고, http는 이 PC 주소만 받습니다.
내 MCP 서버(선택)AI가 도구에 넘기는 값과 도구의 결과, 서버 이름·명령·환경값사용자가 등록한 프로그램을 이 PC에서 실행합니다. 내 API 키나 내 PC 모델 대화에서 AI가 도구를 쓸 때 호출마다 묻습니다. 그 프로그램이 내용을 어디로 보내는지는 그 프로그램을 따릅니다. 설정은 이 기기에만 저장하고 동기화하지 않습니다.
의미 검색(선택)모델 파일(약 558 MB) 다운로드 요청켜면 처음 한 번 huggingface.co에서 공개 임베딩 모델(bge-m3 ONNX)을 받습니다. 받는 것은 모델 파일(데이터)뿐이고 실행 코드는 받지 않습니다. 다운로드한 뒤 계산은 기기 안에서만 하고 글은 밖으로 나가지 않습니다. 모델은 설정에서 지울 수 있습니다.
유튜브 자막 자동 가져오기(선택)인박스에 넣은 유튜브 링크켜면 youtube.com에 그 영상의 자막을 요청해 본문에 넣습니다. 기본은 꺼짐.
브라우저 확장 받기(선택)확장이 보낸 글·링크이 PC의 로컬 주소(loopback)로만 받습니다.
백업·내보내기백업 파일에 담은 앱 데이터와 첨부사용자가 고른 위치에 저장하거나 그 파일을 읽습니다. 전송 없음.
알림일정·알림 시각기기의 알림 기능으로만 띄웁니다.

4. 외부 서비스

Dalfocal은 개인정보를 팔지 않습니다. 아래는 사용자가 해당 기능을 켰을 때만 관여합니다.

  • 사용자가 연결한 AI 앱·AI 프로그램 (Claude Desktop, Claude Code, Codex CLI, Gemini CLI, goose, Cursor 등): 그 앱이 읽은 카드·노트와 대화 글의 처리는 각 제공자의 정책을 따릅니다.
  • 사용자가 고른 AI 회사 (OpenAI, Google, 사용자가 주소를 적은 서비스): 내 API 키를 켰을 때 대화 글과 대화 중 AI가 읽은 카드·노트를 받습니다. 처리와 보관은 각 회사의 약관을 따릅니다.
  • huggingface.co: «의미 검색» 모델 파일을 다운로드하는 곳입니다. 다운로드 요청 외에 다른 데이터를 보내지 않습니다.
  • youtube.com: «유튜브 자막 자동 가져오기»를 켰을 때 자막을 요청합니다.
  • 운영체제: Windows·Android의 보안 저장소, 파일 선택기, 알림, 음성 인식을 씁니다.

5. 보관과 삭제

  • 기기 안 데이터는 사용자가 앱에서 삭제하거나 데이터 폴더를 삭제하거나 앱을 제거할 때까지 남습니다. 휴지통에 넣은 것은 비우면 삭제됩니다.
  • 서버 기기나 중계 서버에 보관된 암호화 데이터는 모든 기기가 받으면 삭제됩니다.
  • 동기화한 다른 기기의 데이터는 그 기기에서 삭제합니다. 동기화 연결은 설정에서 기기별로 빼거나 서버를 다시 만들어 끊을 수 있습니다.
  • 백업 파일은 사용자가 직접 삭제할 때까지 고른 위치에 남습니다.
  • 다운로드한 «의미 검색» 모델은 설정 → AI → «모델 삭제»를 누르면 삭제됩니다.
  • 저장한 API 키는 설정 → AI → 쓸 방식 → 내 API 키에서 «저장된 키 지우기»를 누르면 삭제됩니다.
  • AI 대화는 창을 닫으면 사라집니다. Dalfocal은 대화 내용을 저장하지 않습니다.
  • AI 회사로 보낸 내용의 보관과 삭제는 그 회사의 약관을 따릅니다.
  • goose가 이 PC에 저장한 대화는 goose에서 관리합니다.
  • AI에게 시켜 만든 카드·노트와 자동으로 남긴 블록은 다른 Dalfocal 데이터처럼 앱에서 삭제합니다.
  • Dalfocal 계정이 없으므로 계정 삭제 절차가 없습니다.

6. 보안

  • 기기끼리 동기화는 TLS로 연결하고, 초대에 든 인증서 지문과 맞지 않는 상대는 거부합니다.
  • 동기화로 주고받는 데이터와 첨부는 보내는 기기에서 AES-256-GCM으로 암호화합니다. 암호 키가 없는 중계 서버는 내용을 볼 수 없습니다.
  • 동기화 암호 키와 토큰은 기기 보안 저장소(Windows 자격 증명 저장소·Android Keystore)에 둡니다.
  • 내 API 키와 내 MCP 서버의 환경값도 같은 보안 저장소에 암호화해 둡니다.
  • MCP HTTP와 브라우저 확장 수신은 이 PC 안(loopback)에서만 듣고, 토큰 없는 요청은 거부합니다.

7. 권한

  • Windows: 네트워크(동기화·AI 모델 받기·AI 회사 연결·유튜브 자막, 모두 선택), 파일(첨부·백업·데이터 폴더). 동기화 서버를 켜면 같은 네트워크 안에서만 열리고, Windows 방화벽이 허용을 한 번 묻습니다. 로그인 시 자동 시작은 처음 실행 때 켜지며 첫 실행 화면과 설정 → 시작에서 끌 수 있습니다. 창을 닫으면 알림 영역으로 들어가고, 트레이 메뉴 «끝내기»로 완전히 끕니다.
  • Android: 인터넷(위와 같음), 알림, 카메라(동기화 초대 QR 읽기, 사용자가 누를 때만), 마이크(AI 대화 음성 입력, 처음 누를 때만 묻고 소리는 저장하지 않음), 정확한 알람(일정 알림).

8. 아동

달포컬은 개인정보를 수집하지 않으므로 만 14세 미만 아동의 정보도 따로 받지 않아요. 나이를 묻지 않습니다.

9. 방침 변경

방침이 바뀌면 이 페이지의 «최종 수정» 날짜를 바꾸고, 데이터가 밖으로 나가는 방식이 바뀌면 앱 안에서도 알립니다.

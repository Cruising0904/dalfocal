Dalfocal Privacy Policy

Dalfocal is a local-first kanban and project management app. It works without an account or server. Google Sign-In, synchronization, and Gitea integration operate only when enabled by the user.

Effective: July 17, 2026Last updated: July 17, 2026

1. Controller and contact

The developer and data controller is DEVELOPER_NAME. Privacy inquiries: CONTACT_EMAIL.

2. Data handled by Dalfocal

  • Local content: workspaces, projects, boards, cards, notes, tasks, memos, comments, labels, settings, selected files, and local backups remain on the device by default.
  • Optional Google Sign-In: Google account ID, email address, display name, and profile photo URL. The saved profile is kept in platform secure storage; the Google ID token is not persisted.
  • Optional synchronization: a random device ID, change metadata, synchronized content and settings, and embedded attachments up to 10 MB are sent to the server configured by the user.
  • Optional Gitea integration: server URL, personal access token, account/repository/issue/branch information, and issue content submitted by the user. The token is stored in platform secure storage.
  • Dalfocal currently contains no advertising, analytics, or behavioral tracking SDK.

3. Purpose and sharing

Data is used only to provide the selected app, authentication, synchronization, backup, and repository features. Dalfocal does not sell personal data. Google, a user-configured sync server, a user-configured Gitea server, and the operating system provider process data only as needed for the features the user chooses, under their respective policies.

4. Retention and deletion

  • Local data remains until deleted in the app, app data is cleared, or the app is uninstalled.
  • Disconnecting Google removes the saved Google profile from secure storage. Removing the Gitea token removes it from secure storage.
  • Automatic local backups retain the latest 10 copies by default. Exported backups remain until the user deletes them.
  • Deletion of data sent to a user-configured sync or Gitea server may need to be performed on, or requested from, that server.
  • Dalfocal currently has no mandatory Dalfocal account. If an official account service is introduced, this policy and an account deletion process will be published before launch.

5. Security

Account profile data and Gitea tokens use platform secure storage. HTTPS is recommended for Gitea. The current beta sync protocol does not provide application-level end-to-end encryption; transport security depends on the server and network configured by the user. Local databases and exported backups may depend on device and storage security.

6. Children and changes

Dalfocal is not directed to children and does not knowingly collect children's personal data. This policy will be updated before material data-handling changes, with the last-updated date revised accordingly.
